# TikTok-Style Developer Portfolio

An interactive, video-inspired developer portfolio website modeled after TikTok's user interface and UX patterns. Hosted on an Amazon S3 bucket, this project transforms traditional software engineering portfolio sections into a vertical, snap-scrolling feed of developer projects, technical skill showcases, and interactive profile cards.

---

## Live Demo

Check out the live deployment on Amazon S3:
* **[TikTok Developer Portfolio](https://mybucket970130.s3.eu-north-1.amazonaws.com/index.html)**

---

## Features

- **TikTok UI & UX:** Features full-screen vertical snap-scrolling, engagement sidebars (like, comment, and share interaction controls), and clean overlay cards.
- **Developer Showcase Feed:** Presents personal projects, technical skills, and experience milestones as individual content slides in a social feed format.
- **Pure Web Technologies:** Built strictly using **HTML5**, **CSS3**, and **Vanilla JavaScript** without external UI frameworks, prioritizing fast loading times and smooth scroll mechanics.
- **Responsive Layout:** Optimized across desktop devices and mobile viewports with flexible layout rules and media queries.
- **Cloud Hosting on AWS S3:** Static web hosting configured directly via an Amazon Web Services (AWS) S3 bucket in the `eu-north-1` region.

---

## Tech Stack

| Technology | Layer | Description |
| :--- | :--- | :--- |
| **HTML5** | Structure | Semantic markup for layout feeds, modal views, and video/content cards |
| **CSS3** | Styling | Scroll-snap mechanics, custom overlays, flexbox, CSS Grid, and mobile animations |
| **JavaScript (ES6+)** | Dynamic Logic | DOM management, scroll event observers, and interactive UI controls |
| **AWS S3** | Cloud Infrastructure | Static site hosting and cloud asset storage |
